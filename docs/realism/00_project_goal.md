# Project Goal

The project goal is **paper-grade physical correctness with film-grade visual realism**.

The core principle is that **physical reality and visual interpretation must remain separate**. The final image should become more realistic because both sides improve, not because one side hides defects in the other.

## Physical Reality Layer

Physical reality includes:

- spacetime
- metric
- geodesics
- black hole model
- accretion disk model
- emissivity
- absorptivity
- optical depth
- radiative transfer
- redshift
- Doppler beaming
- raw radiance

This layer defines what exists and what light reaches the observer before display interpretation.

## Interpreter Layer

The interpreter includes:

- eye/camera model
- exposure
- ISO/shutter/aperture
- sensor response
- tone mapping
- bloom
- glare
- lens flare
- depth of field
- final display mapping

This layer defines how already-formed physical light is perceived, measured, or presented.

## Realism Rule

Avoid beauty-only realism. A beautiful image is not enough. Realism must remain explainable through diagnostics such as raw radiance, optical depth, redshift, hit masks, source-location proxies, and presentation-stage debug outputs.
